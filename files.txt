File	Step
read_tracks.py	1 – find the CD and list the tracks
read_audio.py	2 – read one track (3-minute limit)
save_wav.py	3 – save TrackNN.wav into the folder
acr_client.py	ACRCloud connection
identify.py	4 – identify the song and clean the name
filename.py	5 – build the file name
write_disk.py	6 – rename in the same folder
organize.py	6b – group songs into the common artist’s folder
log.py	7 – write log.csv
main.py	runs all of the steps
check_acr.py	tests your ACRCloud keys
identify_wav.py	names WAV files you already have, without a CD
server.py	the optional web page
requirements.txt	requests, fastapi, uvicorn, python-multipart
